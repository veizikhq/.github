# veizik

**One native engine, built to reach every architecture.**

- **NVIDIA** — the main line: image and video generation on your own GPU (FLUX.1 first). In preparation; this page changes when the release is public.
- **Apple Silicon** — local LLM inference on your Mac. Available: [veizik-metal](https://github.com/veizikhq/veizik-metal) (signed, notarized installer; Qwen2.5 · Qwen3).

Goal: the same engine on every hardware architecture, running as many models as possible.

Every benchmark we publish names the device, model, the other engine's version and how each side was timed — wins and losses: https://veizik.com/benchmarks

Proprietary, binary-only; sign in once and activate the device; the first run of a session needs the network, generation does not.
